# 后端加固后的运行约定

## 身份和令牌

登录签发的 JWT 绑定运行时租户，并包含使用现有 JWT 密钥计算的凭据摘要。每次认证读取该租户当前账号与角色：账号或角色停用、删除，或密码、角色标识、数据权限类别、所属部门变化后，原令牌不能继续使用。摘要不包含可读的密码哈希。

升级前签发的令牌没有这些字段，必须重新登录。配置 `*` 数据库的单租户部署仍允许同一数据库的多个 Host 别名；命名租户按配置的 Host 精确匹配。不再把未知 Host 传给空数据库连接。

这些检查每个认证请求增加两次有主键条件的读取。退出接口会递增账号的 `auth_version`，撤销该账号的全部已签发会话；没有独立会话表，也不提供逐个设备或令牌的撤销管理。账号或角色停用后再启用不会恢复旧令牌；用户名、角色、部门或数据权限变更后再恢复原值，也不会恢复旧令牌。昵称、联系方式和头像更新不会主动撤销会话。

启动新版服务前，先通过原有 `migrate` 命令应用 `1786700013000_auth_version` 迁移；不要在请求路径自动改表。迁移为现有账号补充默认值 0，重复执行不会清除已记录的撤销计数。JWT 签名和凭据摘要共同使用进程启动时的密钥，修改 `jwt.secret` 后需重启生效。

`/ws/:id/log` 保留前端生成 UUID 的连接方式及日志消息格式。当前日志源是固定的进程级文件 `temp/logs/job/db-20200820.log`，因此只允许通配租户 `*` 的管理员访问；命名租户及其他频道返回拒绝。生产环境 Origin 必须与请求 Host 匹配；开发模式下，前后端都使用回环地址时允许不同端口，以兼容内置开发服务器（无 Origin 的非浏览器客户端仍需令牌）。连接按租户、账号、UUID、频道归属管理；退出会关闭本机该账号连接，其他实例通过定期认证检查关闭，正常检查间隔为 1 秒。文件不存在返回 503，不会终止进程。

## 数据与权限更新

角色、菜单关联和持久化 Casbin 规则在同一数据库事务中更新，事务提交失败会返回错误。角色标识变更清理旧标识规则。提交后刷新本实例权限缓存；刷新失败返回明确错误并清空旧缓存，此时持久化修改已经提交，重试前应重新读取角色。

其他实例沿用 core 的周期性权限重载。外部自定义 Casbin watcher 的即时通知不在本次实现范围内，部署如依赖它需提供事务提交后的通知集成。

部门和菜单移动同时更新子树路径，拒绝自指、子孙作为父节点及不存在的父节点。树写操作按节点 ID 顺序加锁，优先保证管理数据一致性。

字典类型重命名会在同一事务内迁移有效字典项，存在有效字典项时拒绝删除类型。字典项写入先验证并锁定父类型，避免与重命名或删除交错后留下孤立引用。配置批量写入遇到错误整体回滚；读取指定配置时排除已删除数据。

前端 `useDict` 仍有浏览器进程内缓存；后端修改完成后，已打开页面可能需要刷新才能重新获取字典。本轮未修改前端缓存机制。

## 定时任务

任务 `status=2` 表示期望运行，`status=1` 表示停止。启动和停止会持久化状态；重复启动不会注册多个副本。修改、禁用和删除后同步本地领导实例的调度器，其他实例上的修改由领导实例在下一次心跳（10 秒）读取。

租约续期 I/O 使用截止时间，独立计时器在租约到期时停止调度；真正调用任务前再次检查租约。已经开始的外部任务仍可能在接管后继续完成，业务任务必须自行保证幂等性；此机制不提供外部副作用的恰好一次执行。

## 配置与上传

数据库连接配置属于进程生命周期资源。重复加载相同配置保留现有连接池、权限引擎和调度器；连接参数或租户集合变化会记录需要重启的错误，必须重启服务才能应用。

`/static/uploadfile/` 上传资源带 CSP sandbox；非栅格图片类型以附件返回。现有 HTML/SVG 文档不再作为管理站点同源的活动页面执行。栅格图片仍可用作头像。

操作日志保留结构化普通字段，递归遮盖密码、令牌和密钥字段。无效、截断及非结构化请求正文不记录；请求处理器仍收到完整原始正文。连接串日志只展示解析后的安全信息，无法识别的格式省略。

缓存和队列由创建它们的生命周期持有，配置重载后关闭旧代资源；缓存等待已进入的操作完成再关闭连接。未配置队列时也创建可排空的内存队列。Redis 就绪探测将请求截止时间传递到 socket I/O；旧版自定义缓存接口不支持取消时，最多保留一个正在等待的探测操作。关闭预算约束等待时长，无法强制终止第三方阻塞操作或已运行的业务任务。

## 开发验证

最低工具链为 Go 1.27.3。CI 覆盖 `gatework` 和功能、修复、同步分支，并运行 `govulncheck`。数据库回归测试沿用 `GO_ADMIN_TEST_POSTGRES_DSN`，只能指向专用测试数据库。

通用 Action 的可选 `UpdateFields() []string` 契约用于更新字段存在性：显式零值会写入，遗漏字段保留原值，主键、创建人及创建/删除时间不能通过它覆盖。现有第三方 DTO 不实现该方法仍保留旧的非零值更新语义。示例模块和定时任务 DTO 已接入，可作为迁移参照。

## 上传失败处理

上传请求上限为 32 MiB（包含 multipart 或 Base64 编码开销），临时 multipart 数据在请求结束时清理。Base64 图片校验编码与真实图片类型，并按实际格式保存；缺少文件、无效编码、写入或对象存储失败只返回一次结构化错误。

上传响应保留既有 URL 契约：单文件的 `path` 与 `full_path` 为相对路径；多文件和 Base64 仅在 `source=1` 时返回绝对 `full_path`。系统设置页仍可拼接服务地址。

失败请求已创建的本地文件会清理。对象存储批量上传不承诺跨服务原子回滚：远端成功写入后若后续对象失败，当前存储接口没有删除补偿能力；调用方应按失败处理，不能把整个批次视为成功。真实云存储尚需部署凭据下的集成验证。
